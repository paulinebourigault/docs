Certior is a drop-in safety wrapper for AI agent tool calls. Before any tool runs, Certior checks that the agent has the right capabilities, that the content contains no policy violations, and that the call fits within the agent's spending ceiling. Allowed calls return a signed certificate tied to a Lean-verified policy model. Blocked calls raise `CertiorBlocked` with a precise, human-readable reason. One import, one class, one decorator — and your agents operate inside provable boundaries.

## How it works in three steps

Every tool call travels through the same three-step pipeline before your executor ever sees it.

<Steps>
  <Step title="Install and configure a Guard">
    Install Certior with pip and create a `Guard` with the permissions, policy, and budget your agent is allowed to use. Zero mandatory configuration — sensible defaults let you start immediately and tighten the boundary later.

    ```bash
    pip install certior
    ```
  </Step>
  <Step title="Verify before you execute">
    Pass every tool call through `guard.verify()` or decorate your tool functions with `@guard.wrap()`. Certior runs the Capability, Content, and Budget gates in sequence, typically in under ten milliseconds.

    ```python
    from certior import Guard, CertiorBlocked

    guard = Guard(permissions=["network:http:read"], budget_cents=5000)

    result = guard.verify(
        tool="web_fetch",
        params={"url": "https://example.com"},
        required_capabilities=["network:http:read"],
        cost_cents=2,
    )

    if result.allowed:
        output = web_fetch(result.redacted_params)
    ```
  </Step>
  <Step title="Collect signed certificates for audit">
    Every call that passes a real Z3 verification returns a signed `certificate` bound to the Lean policy fingerprint. Persist these in your `audit_log` and replay them at any time to prove exactly which policy was in force when each tool ran.

    ```python
    for entry in guard.audit_log:
        print(entry["tool"], entry["allowed"], entry["latency_ms"])
    ```
  </Step>
</Steps>
